# Bauteile-Suche

Für den Versuch zur Signalverarbeitung werden bestimmte elektrische Bauteile benötigt. Damit diese nicht mühevoll in der E48 Reihe gesucht werden müssen, befindet sich hier ein Python-Skript, das für gegebene Eingangs- und Ausgangssignale die geeigneten Bauteile aus der E48 Reihe auswählt und die damit verbundene Unsicherheit berechnet.

Das Python-Skript `Bautile.py` berechnet die Bauteile und sucht die passenden Widerstände in der E48 Reihe.

Die Simulationen können mit `ngspice` aus der Kommandozeile ausgeführt werden.
